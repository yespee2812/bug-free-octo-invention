## Version A — Indian writers (₹500)

Hi [Name],

Thank you for agreeing to help with **ScriptLens** — a tool that flags story continuity problems in screenplays (timeline slips, props changing hands, character contradictions, etc.).

**What you get from me**
- One **5-scene** starter script  
- One **10-scene** starter script  
- One **full-length** pre-produced feature script  
- Word instructions, 1-page cheat sheet PDF, and blank answer sheet template  

**What you do**
Inject **deliberate continuity mistakes** into all three scripts — write naturally, like a normal draft. Do not write for a machine. We run ScriptLens and compare results to your answer sheet.

| Script | Errors to inject |
|--------|------------------|
| 5-scene | 2–3 |
| 10-scene | 4–5 |
| Full-length | 8–12 |

Use **at least 8 different error types** across all three (death/alive, timeline, props, injuries, relationships, location clash, etc.). Full list is in the attached Word brief.

**What you return (6 files)**
- 3 edited scripts + 3 answer sheets (one log per script)  
- Name files: `[Surname]_5scene_errors`, `[Surname]_10scene_errors`, `[Surname]_feature_errors` (+ matching `_ERROR_LOG` files)  
- Scene numbers: Scene 1 = first `INT.`/`EXT.` in the file  

Each answer sheet must list every planted error with establishing scene, contradicting scene, and quotes/paraphrase of both moments.

**Payment:** **₹500** on delivery, via [UPI / bank transfer — add your method].  
**Deadline:** [DATE]  
**Submit to:** [EMAIL / Drive link]  

Scripts are used **only for internal testing**, not published or produced.

Questions — reply anytime. Thanks for helping make this useful for working writers.

Best,
